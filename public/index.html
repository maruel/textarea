Textarea

A minimalist text editor that lives entirely in your browser and stores everything in the URL hash.

Features

  • 🗜️ Compression – your text is compressed with deflate
  • 🔗 URL hash – share your notes by copying the URL
  • 💕 Style – customize the look with CSS via DevTools
  • 🎤 Dictation – speech recognition types at the caret

Keys

  • F1 – this help
  • F2 – start and stop dictation
  • Ctrl+S – save as HTML

Pro tips

  • Start the document with # Title to set the page title
  • Add a style attribute to the <article> tag via DevTools. It is saved in the URL too
